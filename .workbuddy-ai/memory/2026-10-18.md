## Auth gate + login routing (later same day)
- `MicrogridContext` exposes `currentUser`, `signIn`, `signOut`, `pendingPage`, `requestPage`. `requestPage` is the gate: home/login + already-authenticated users pass through, everything else sets `pendingPage` and routes to `login`.
- `src/auth/LoginPage.tsx` (split screen, forest brand panel + cream form, demo workspace with `Autofill demo credentials`).
- Demo credentials in `MicrogridContext.tsx`: `operator@gridheal.lab` / `GridHeal#2026`. `signIn` sets `currentUser = { email, name: 'Samarth Darak' }` and redirects to `pendingPage ?? 'overview'`.
- `App.tsx` must import `LoginPage` and return it when `activePage === 'login'` — without that route the gate sets the page but nothing renders.
- `useGo` in `src/home/ui.tsx` must return `requestPage` (not raw `setActivePage`) — otherwise every `go(...)` bypasses the gate.
- `Navbar.tsx` desktop + mobile drawer use the auth state: anonymous shows `Sign In` + `Launch Recovery Lab`; signed-in shows `Sign Out` + `Open Recovery Lab`. Mobile drawer shows `Signed in as {email}`.
- `TopNav.tsx` user dropdown now also gets a `Sign out` button + `Signed in as {email}` line, using `LogOut` icon.
