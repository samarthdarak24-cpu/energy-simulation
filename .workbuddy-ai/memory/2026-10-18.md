## UI audit vs 9 reference screenshots
- All 9 screens exist and route from `Sidebar.tsx` → `App.tsx`: Overview, Twin, Fault Studio, Prediction, Recovery, Benchmark, Event Logs, Settings, Help.
- Overall verdict: 2 screens faithful (Prediction, Help), 5 with minor visual/data-binding gaps (Overview, Twin, Fault Studio, Recovery, Benchmark), 2 with broken interaction (Event Logs, Settings).
- Key findings:
  - Settings: `activeTab` state is set but never used to switch content — all 6 tabs render Asset Configuration. Also missing the "Grid Import/Export Limits" chart in Grid Connection Settings.
  - Event Logs: `eventTypeFilter`/`severityFilter`/`statusFilter`/`searchTerm` are never applied to the table; `selectedEventId` changes but the right "Event Details" panel is hardcoded to the solar event. Pagination buttons inert.
  - Twin: energy-flow diagram hardcodes 128/37/52/28/18/7 kW and +22 kW instead of reading `telemetry`; no connector lines between nodes. Start Sim / Pause set unused `isPaused`.
  - Fault Studio: "Fault Impact Preview" hardcoded to Solar Generation Loss; `duration` and `startTime` never passed to `injectFault`; 3 inert buttons.
  - Recovery: header Auto Recovery toggle desyncs from the hardcoded "ON" badge in the right rail; 5 metric cards hardcode values instead of `telemetry`.
  - Benchmark: x-axis labels truncated via `cat.name.split(' ')[0]`; "emissions"/"renewable" trend tabs render lowercase; chart paths identical for every tab.
  - Overview: Total Supply / Grid Import / Unserved strip belongs in the right rail (reference) but sits in the left column; bottom 4 cards should span full width. Top-right CTA should read "Run Simulation", code returns "Run Recovery".
  - Global: `searchQuery` is written by TopNav but never read by any view — global search is decorative. `forecastData`, `dismissAlert`, `clearFault`, `faultSeverity` are provided but unused. ~18 `onClick={() => {}}` handlers across views.
  - Note: the Overview reference screenshot (1ui.png) predates the GridHeal rebrand — it shows "Recovery Lab" as the brand and a "Recovery Lab" promo card. Current code follows the newer 8-screen branding, so that difference is intentional.
